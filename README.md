# InviteMe
InviteMe is an event creation application that will allow users to create social events, invite others, and add channels*** for event customization.
This project uses the MERN stack and Tailwind and will eventually be deployed using Docker and AWS.
The goal of this project is to refine and continue building web development skills, while also getting familiar with deploying applications using Docker and AWS.

## Current Project Progress
* All Event CRUD operations complete.
  - Backend established with Node.js and Express.js
  - Database established using MongoDB/Mongoose
  - Frontend uses RESTful APIs to perform CRUD operations with backend and database
* Frontend refined using Tailwind


## Next goals
* Expanding application capabilities to allow the user to add:
  - Create account and login
  - Invite others to an event
  - Create channels*** for an event 
* Refine frontend to include more interaction.
* Deployment of application


*** 
Channels will allow users to make events customizable and collaborative, especially for trips or larger social events. 
Examples of these could include trip housing, food, activities, etc., but is designed to allow the user to coordinate and encourage
collaboration among invitees
