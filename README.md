# CalendarApp
Personal calendar and journal application for creating events and appointments that also allows the user to create goals and reflect on them.
This project uses the MERN stack with the eventual goal of deploying and hosting using AWS.
The goal of this project is to refine and continue building web development skills, while also getting familiar with deploying applications using Docker and AWS.

## Current Project Focus
* Establishing the backend and frontend for the calendar and creating simple events
  - Backend and MongoDB database are complete (2/20/2025)
* Dockerizing the application for eventual deployment

## Next goals
* Expanding application capabilities to allow the user to add:
  - Goals for a day/week/month: establishing a focus to work on within that time period.
  - Reflection on day/week/month to serve as a journal or simply acknowledging goal progress]
* Deployment of application
